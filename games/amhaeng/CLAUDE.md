# 암행

저장소 전체에 걸리는 규칙은 루트 `CLAUDE.md`에 있다. 여기에는 이 게임에만
해당하는 것만 적는다.

Shogun Showdown(2023)을 따른 한 줄 턴제 로그라이트. 암행어사가 고갯길·고을·깊은 산을 지나며
산적·탐관오리·요괴와 싸운다. 폴더와 식별자는 `amhaeng`이다. 원작의 일본 무사 배경을 조선의
설화와 사극을 섞은 배경으로 옮겼고(사용자와 정함), 이름도 그래서 제 이름을 쓴다.

**알파다.** 한국어만 있고 오늘의 도전에 넣지 않았다. 그림은 도형(`art.js`)이다 — 시안을 받으면
`figure(kind)`가 돌려주는 것만 바꾸면 된다.

## 명령

```bash
node games/amhaeng/battle.test.js   # 싸움 규칙: 준비·헛침·제 편 맞히기·패마다의 효과·운 없음
node games/amhaeng/run.test.js      # 여정: 싸움 뒤 보상, 주막, 서낭당, 고을 넘기, 저장본 읽기
```

## 원작과 다른 것

- **싸움 도중에는 저장하지 않는다.** 닫았다 열면 그 싸움 앞(지도)으로 돌아온다. 한가운데를
  저장해 두면 나쁜 수를 둔 뒤 다시 열어 되돌리는 길이 된다.
- 마패는 처음에 주지 않고 첫 우두머리 뒤 보상에만 나온다. 모든 적을 묶는 패라 처음부터 있으면
  첫 고을이 거저다.
- 싸움이 끝날 때마다 체력 1을 되찾는다(`REST`). 까닭은 `data.js`의 `PAY` 위에 있다.

## 균형

사람 대신 세 수 앞을 보는 봇으로 여정을 돌려 쟀다(저장소에 두지 않았다). 지금 수치에서 봇은
절반쯤이 둘째 고을을 넘고 셋째 고을에서 쓰러진다. 봇은 택견·축지법처럼 피해가 없는 패의 쓸모를
읽지 못하고, 적을 끌어들여 서로 치게 하는 수도 거의 못 두므로 사람의 아래 한계로 본다.
