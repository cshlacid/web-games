# 스도쿠

저장소 전체에 걸리는 규칙은 루트 `CLAUDE.md`에 있다. 여기에는 이 게임에만
해당하는 것만 적는다.

## 명령

```bash
node games/sudoku/logic.test.js   # 기법·생성기 테스트
```

## 힌트

넣은 숫자가 정답과 다르거나 연필 표시가 정답 숫자를 지워 두었으면 그 칸을 짚고 멈춘다.
없으면 `solver.nextStep`이 **넣은 숫자와 연필 표시(있는 칸은 그것을 후보로 친다)에서 기법을
쉬운 순서로 보고 처음 새로 알게 된 것 하나**를 돌려준다. 칸이 확정되면 숫자를 넣고, 후보만
줄면(짝·세 칸·가리키기·X-Wing 같은) 그 칸들의 후보를 연필로 남기고 무엇을 뺐는지 알린다.

예전에는 후보만 지우는 기법을 속으로 거친 뒤 처음 확정된 칸을 주고 마지막 기법 이름만
알렸다. 그 사이가 가려져 이유 없이 떨어진 숫자로 보였다. 연필로 남기지 않으면 다음 힌트가
같은 걸음을 다시 짚어 제자리걸음이 된다.
