# 핍스

저장소 전체에 걸리는 규칙은 루트 `CLAUDE.md`에 있다. 여기에는 이 게임에만
해당하는 것만 적는다.

NYT Pips(2025)를 따른 도미노 놓기 퍼즐. 주어진 도미노를 모양이 고르지 않은 판에 빠짐없이 놓고,
색칠한 구역마다 조건(합, 작다, 크다, 같음, 다름)을 맞춘다. 폴더와 식별자는 `pips`다.

## 명령

```bash
node games/pips/rules.test.js      # 판 자료 읽고 쓰기, 구역 판정, 놓을 수 있는 자리
node games/pips/solver.test.js     # 구역 조건, 방향 고르기, 구운 판의 답이 하나인지, 힌트로 끝까지
node games/pips/generator.test.js  # 구워 둔 판 180장을 다시 푼다

node games/pips/bake.js > games/pips/puzzles.js   # 다시 굽기(4분쯤, 거의 어려움)
```

## 답이 하나라는 것

**도미노가 가는 자리만 하나로 정하고 방향은 정하지 않는다**(까닭은 `solver.js` 머리말). 그래서
정답은 정해 둔 답과 맞추지 않고 규칙으로 가리고, 힌트도 정답과 방향이 다르다는 것만으로 틀렸다고
하지 않는다. NYT도 답이 여럿인 판을 그대로 낸다 — 어려움에는 수천 가지인 날도 있다.

## 판은 미리 굽는다

쉬움 5×5 상자(도미노 5~6), 보통 6×6(8~9), 어려움 7×7(11~13)을 예순 판씩. **한 칸짜리 구역이
많은 것은 일부러가 아니라 답을 하나로 모은 대가다** — 까닭은 `bake.js`의 `LEVELS` 위에 있다.

## 조작

**누르기(아래에서 고르고 판의 칸을 누른다)와 끌기를 둘 다 둔다.**
누른 칸이 판 끝이거나 옆이 막혔으면 한 칸 비켜 놓는다 — 도미노 반쪽 중 어느 쪽이 누른 칸에 갈지
사람이 정확히 겨누지 않는다. 끌 때는 비켜 놓지 않는다. 손가락을 따라오는 모양이 곧 놓일 자리다.
