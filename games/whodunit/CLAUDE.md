# 범인 찾기

저장소 전체에 걸리는 규칙은 루트 `CLAUDE.md`에 있다. 여기에는 이 게임에만
해당하는 것만 적는다.

Clues by Sam(2025)을 따른 추리 퍼즐. 4×5에 앉은 스무 명의 정체(무고·범인)를, 밝혀진 사람이
하나씩 말하는 단서로 가려낸다. 폴더와 식별자는 `whodunit`이다. 원작 이름에 사람 이름이 들어
있고 이 장르를 부르는 다른 이름이 없어, 하는 일을 이름으로 삼았다(사용자와 정함).

**알파다.** 단서 문장이 갈래마다 따로라 규칙이 자리 잡기 전에 여섯 언어를 같이 고치면 일이
여섯 배가 된다. 한국어만 있고 오늘의 도전에 넣지 않았다. 알파를 떼면 이름 목록과 단서 문장을
다른 언어로 채운다 — 이름 목록은 언어마다 그 언어의 가나다순이어야 한다(판 위의 이름 차례).

## 명령

```bash
node games/whodunit/rules.test.js      # 무리·단서 판정, 판 자료 읽고 쓰기
node games/whodunit/solver.test.js     # 단서 하나로 정하기, 정해졌는지 가리기, 구운 판·힌트로 끝까지
node games/whodunit/generator.test.js  # 구워 둔 판 180장을 다시 푼다

node games/whodunit/bake.js > games/whodunit/puzzles.js   # 다시 굽기(1분쯤, 거의 어려움)
```

## 밝히기

**단서로 정해지는 사람만 밝힐 수 있다.** 아직 둘 다 될 수 있는 사람을 고르면 근거가 부족하다고만
하고 실수로 치지 않는다. 정해졌는데 반대로 고르면 실수다. 원작이 그렇게 하고, 찍어서 맞히는 길을
막아야 추리가 남는다. 정해졌는지는 풀이기의 걸음 수와 상관없이 끝까지 뒤져 가린다 — 사람이
풀이기보다 깊이 따졌어도 받아 준다.
